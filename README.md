# Personal Portfolio Website

## Project Overview
The Personal Portfolio Website is a web development project created to present my professional introduction, education, skills, projects, and contact information in an organized format.

## Objectives
- Build a personal portfolio website using HTML and CSS.
- Organize personal and educational information into separate pages.
- Present technical skills and projects.
- Practice website structure, styling, and file organization.

## Technologies Used
- HTML5
- CSS3
- Visual Studio Code
- Git and GitHub

## Features
- Home page
- About page
- Education page
- Skills page
- Projects page
- Contact page
- Images and styling resources

## Project Structure
- `index.html` — Home page
- `about.html` — About page
- `education.html` — Education page
- `skills.html` — Skills page
- `projects.html` — Projects page
- `contact.html` — Contact page
- `style.css` — Website styling
- `images/` — Image assets

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Navigate through the available pages.
